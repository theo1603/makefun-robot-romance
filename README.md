A single original one-line joke pickup line aimed at a robot / an AI, written for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. The program writes the line to `/output/entry.txt`; an AI judge duels it head to head against other entries.

## Run it

```sh
python3 main.py
```
